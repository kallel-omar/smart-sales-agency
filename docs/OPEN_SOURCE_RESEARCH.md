# Open-source research notes

This starter was written as a clean implementation. It does not copy source files from the projects below.
Their public architectures and documented ideas were studied as references:

1. SalesGPT — sales-stage awareness and product/tool grounding. MIT license.
2. sales-outreach-automation-langgraph — research -> qualification -> personalized outreach graph.
   No clear repository license was visible during review, so its code was not copied.
3. b2b-sdr-agent-template — layered business context, staged pipeline, memory, follow-up checks,
   delivery queue, and human-like communication. MIT / MIT-0 metadata is shown in the project.
4. OpenCloser v2 — named sales-agent roles, lead research, CRM pipeline, coaching, and manager views.
   MIT license.

Before copying any third-party file into a commercial product, verify the exact license at the commit
being used and preserve all required copyright and license notices.
