# HIRI Agent Instructions

## HIRI UI/UX Design Rules

All frontend, interface, dashboard, landing-page, visualization,
animation, and 3D work MUST follow:

docs/design/HIRI_UI_UX_DESIGN_SYSTEM.md

Before implementing or modifying any HIRI UI:

1. Read docs/design/HIRI_UI_UX_DESIGN_SYSTEM.md.
2. Inspect existing HIRI components and adjacent screens.
3. Reuse existing components whenever possible.
4. Do not introduce generic AI/SaaS design patterns.
5. Do not redesign existing working screens unnecessarily.
6. Keep business logic separate from visual changes.
7. Motion must have a functional purpose.
8. 3D must only be used where it adds meaningful product value.
9. Preserve performance, accessibility, and responsive behavior.
10. Maintain one coherent HIRI visual identity across all departments.
